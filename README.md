# بوت واتساب روز (نسخة Baileys الخفيفة)

## إيه اللي اتغيّر عن النسخة القديمة؟
النسخة دي بقت تستخدم مكتبة `@whiskeysockets/baileys` بدل `whatsapp-web.js`. الفرق العملي:
- **مفيش متصفح Chromium** بيشتغل في الخلفية → البوت بقى أخف بكتير في الذاكرة (RAM).
- بيشتغل عادي كـ Node.js app بسيط، فبيتظبط على استضافات مجانية خفيفة مش كانت هتكفي مع النسخة القديمة.
- التعامل مع الرسائل والردود اتحول لصيغة Baileys لكن **كل مميزات البوت (الـ FAQ، الطقس، الردود الذكية، الذاكرة) موجودة زي ما هي بالظبط**.

## المتطلبات
- Node.js 18 أو أحدث.

## خطوات التشغيل محليًا
1. افتح Terminal في مجلد المشروع.
2. ثبّت المكتبات:
   ```
   npm install
   ```
3. شغّل البوت:
   ```
   npm start
   ```
4. هيظهرلك QR code في الـ Terminal (أو تقدر تفتحه من المتصفح على `/` بعد ما تشغّل السيرفر). افتح واتساب على موبايلك:
   - الإعدادات > الأجهزة المرتبطة > ربط جهاز
   - امسح الـ QR code
5. لما تشوف رسالة "✅ روز V7 الذكية جاهزة 🌹" يبقى البوت شغال.

## متغيرات البيئة (Environment Variables)
لازم تظبطها في أي استضافة هتستخدمها:
- `GROQ_API_KEY` — مفتاح Groq للردود الذكية.
- `GROQ_MODEL` — اختياري، افتراضيًا `openai/gpt-oss-120b`.
- `TAVILY_API_KEY` — اختياري، للبحث في النت.
- `PORT` — بتحددها الاستضافة نفسها غالبًا تلقائي.

## حفظ الجلسة
جلسة واتساب بتتحفظ في مجلد `auth_info_baileys` (بدل `.wwebjs_auth` القديم). لو الاستضافة بتمسح الملفات لما السيرفر يعيد التشغيل، هتحتاج تمسح QR تاني في كل مرة — ده أهم سبب ننقل تخزين الجلسة لقاعدة بيانات خارجية (خطوة تالية لو حابب).

## إبقاء البوت صاحي على استضافة مجانية بتـ"ينام"
فيه نقطة `/ping` جاهزة في الكود ترجع `pong`. تقدر تظبط خدمة مجانية زي `cron-job.org` تبعت طلب على الرابط ده كل كام دقيقة عشان تمنع السيرفر من النوم.

## ملاحظات مهمة

- لو استخدمت رقمك الشخصي، هيرد باسمك انت. لو عايز تفصل، استخدم رقم مخصص للبوت.
